# Magic Math Kids 🪄✨

A simple, playful math learning app for kids built as a single HTML file.

Originally created to help a first-grade child practice basic arithmetic in a fun and distraction-free way.

No installation required. No frameworks. No dependencies. Just open the HTML file in a browser and start practicing.

Perfect for practicing arithmetic on desktop and tablets.

---

## Features

### Version 1

* Manual operation entry
* Exercise generation
* Answer validation
* Progress tracking
* Active exercise highlighting
* Celebration screen
* Emoji confetti effects

### Version 2

* English user interface
* Automatic focus on the next exercise
* Automatic scrolling
* Keyboard-only workflow

### Version 3

* English and Spanish support
* Language selector
* Translated UI messages
* Translated warnings
* Translated progress indicators

## Running Locally

Simply open the HTML file in a modern browser.

For the best experience on tablets and mobile devices, hosting through GitHub Pages or a local web server is recommended.

Example:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
